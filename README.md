# Projet QI — Probabilité d'extinction d'espèces 🐇🐺

Projet réalisé dans le cadre du cours de **Quantification de l'Incertitude (QI)** à l'École Centrale Nantes.

## 📌 Description

Ce projet étudie la **probabilité d'extinction simultanée d'un système proie-prédateur** de type Lotka-Volterra, en prenant en compte les incertitudes sur les paramètres du modèle.

L'étude combine **modélisation mathématique, simulation numérique et quantification de l'incertitude** afin d'analyser l'influence des paramètres sur la dynamique du système et sur le risque d'extinction.

## 🛠️

* Python
* OpenTURNS
* NumPy
* Matplotlib
* Jupyter Notebook

## 🔬 Méthodes

* Résolution numérique d'équations différentielles
* Propagation d'incertitudes
* Simulation de Monte Carlo
* Subset Sampling
* Kernel Smoothing
* Modélisation probabiliste sous contraintes
